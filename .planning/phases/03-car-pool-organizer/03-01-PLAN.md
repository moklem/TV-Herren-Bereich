# Phase 03 Plan 01: Event Schema + GET /:id carPool Population

## Objective

Extend the Event mongoose schema with the `carPool` embedded sub-document and add population of carPool player references to the `GET /api/events/:id` route. This is the foundation all other Phase 3 plans build on.

## Context

- @server/models/Event.js — add carPool sub-document schemas before the closing `}, { timestamps: true }` on line 304. The existing `quickFeedback` field is the last field. Insert `carPool` after it.
- @server/routes/eventRoutes.js — the `GET /:id` route at line 496 does NOT exclude carPool (only the list endpoints at lines 428 and 481 exclude it with `.select('-carPool')`). Add three `.populate()` calls to the GET /:id chain. Do NOT touch lines 428 or 481.
- No new npm packages. No new files.

<name>Add carPool sub-document schemas to Event.js</name>
<files>server/models/Event.js</files>
<action>
Add two new schema definitions before the existing `const EventSchema = new mongoose.Schema({` line (line 3), and add the `carPool` field to EventSchema after the `quickFeedback` array field.

**Add before line 3 (before `const EventSchema`):**

```javascript
const carPoolDriverSchema = new mongoose.Schema({
  player: { type: mongoose.Schema.Types.ObjectId, ref: 'User', required: true },
  seats: { type: Number, required: true, min: 1, max: 9 },
  note: { type: String, default: '' },
  passengers: [{ type: mongoose.Schema.Types.ObjectId, ref: 'User' }]
}, { _id: false });

const carPoolSchema = new mongoose.Schema({
  finalized: { type: Boolean, default: false },
  drivers: [carPoolDriverSchema],
  passengers: [{ type: mongoose.Schema.Types.ObjectId, ref: 'User' }]
}, { _id: false });
```

**Add the `carPool` field inside EventSchema** after the closing `}]` of the `quickFeedback` array (just before the closing `}, { timestamps: true }` on line ~304):

```javascript
  carPool: { type: carPoolSchema, default: () => ({}) }
```

The result should look like:
```javascript
  quickFeedback: [{
    // ... existing quickFeedback fields ...
  }],
  carPool: { type: carPoolSchema, default: () => ({}) }
}, {
  timestamps: true
});
```

**Important:** Do NOT modify any existing fields, indexes, pre/post hooks, or the module.exports line.
